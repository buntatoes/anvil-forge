## Scripts and WebAssembly 1.0 (`WASM`)

`anvil-script` runs timers, promises, WebAssembly 1.0 modules, and DOM mutations on its own event loop. After each task the whole microtask queue is drained. Timers fire by due time, then in the order they were set, on a virtual clock that does not follow wall time. A timer set while a timer callback itself runs waits at least 4 ms. Timers set from the microtasks that callback queues, or after an `await` in an async timer callback, keep the delay they ask for.

Supported:

- WebAssembly 1.0 (`\0asm` version `1`) binary module decoding (`WasmModule::decode`), validation (`validate_wasm`), bounded 64 KiB page linear memory (`WasmMemory`, up to 2,560 pages / 160 MiB), and stack machine execution (`WasmInstance::instantiate`, `call_export`, `get_exported_global`, `set_exported_global`) covering `i32`, `i64`, `f32`, and `f64` arithmetic, bitwise, comparison, conversion, load/store, `memory.size`, `memory.grow`, `memory.copy`, `memory.fill`, and structured control flow (`block`, `loop`, `if`/`else`, `br`, `br_if`, `br_table`, `call`, `call_indirect`, `return`)
- JavaScript `WebAssembly` API: `WebAssembly.validate`, `WebAssembly.compile`, `WebAssembly.compileStreaming`, `WebAssembly.instantiate`, `WebAssembly.instantiateStreaming`, `new WebAssembly.Module`, `new WebAssembly.Instance`, `new WebAssembly.Memory`, `new WebAssembly.Global`, `new WebAssembly.Table`, calling exported WASM functions (`instance.exports.<fn>(...)`), and `memory.grow(delta)`
- `TypedArray` and binary web APIs: `Uint8Array`, `Uint8ClampedArray`, `Int8Array`, `Uint16Array`, `Int16Array`, `Uint32Array`, `Int32Array`, `Float32Array`, `Float64Array` (including views over `WasmMemory` buffers), `ArrayBuffer`, `DataView`, `TextEncoder`, `TextDecoder`, `atob`, `btoa`, `structuredClone`, `URLSearchParams`, `DOMParser`, `AbortController`, `AbortSignal`, `Headers`, `Request`, `Response`, `Event`, `CustomEvent`, `ErrorEvent`, and `PromiseRejectionEvent`, plus ES2022–ES2024 Generators (`function*`, `yield`, `yield*`), Async Generators (`async function*`, `for await...of`, `[Symbol.asyncIterator]`), `BigInt`, ES module `import`/`export`/`import.meta`/`import()` lowering, `Proxy`/`Reflect`, `WeakMap`/`WeakSet`/`WeakRef`/`FinalizationRegistry`, `Symbol.for`/`Symbol.keyFor`, `Error(..., { cause })`, `AggregateError`, `Intl`, W3C 3-phase DOM event propagation (`Capture -> Target -> Bubble`), live layout/scroll DOM geometry (`getBoundingClientRect()`, `getComputedStyle(el, pseudoElt)`, `offsetWidth`/`offsetHeight`, `clientWidth`/`clientHeight`, `scrollWidth`/`scrollHeight`, `scrollTop`/`scrollLeft`, `scrollTo`/`scrollBy`), HTML5 `<dialog>` (`show()`, `showModal()`, `close()`, `returnValue`, `close` event), HTML5 Form Constraint Validation (`validity`, `validationMessage`, `willValidate`, `checkValidity()`, `reportValidity()`, `setCustomValidity()`, `invalid` event), `File`/`FileList`/`FileReader`/`DataTransfer`/`navigator.clipboard`, `Element`/`ChildNode`/`ParentNode` mutation methods, `TreeWalker`/`NodeIterator`/`Range`/`Selection`, `history.pushState`/`replaceState`/`popstate`, `crypto.getRandomValues`/`randomUUID`/`subtle.digest('SHA-256')`, `performance.mark`/`measure`, and 2D `<canvas>` transforms/bezier curves/gradients/`getImageData`/`putImageData` on `cinder::vm::Vm` + `CinderDomHost` (`eval_with_cinder_engine`)
- Interactive hydration (`ScriptRuntime::hydrate_interactive_bindings`) for documents returned from the browser's `--renderer` process, preserving `onclick`/`oninput`/`onchange`/`onsubmit`/`onkeydown` attributes, `addEventListener('click' | 'input' | 'change' | 'submit' | 'keydown', ...)` listeners, ES2022+ `CinderVM` interactive scripts, and declared functions/classes in the browser window without re-running initial DOM mutations
- Microtask-queued `MutationObserver` (`observe` with `childList`, `attributes`, `characterData`, `subtree`, `disconnect`, `takeRecords`), `IntersectionObserver` (`observe`, `unobserve`, `disconnect`, `takeRecords`), and `ResizeObserver` (`observe`, `unobserve`, `disconnect`) callbacks (with live scroll/resize re-evaluation via `ScriptRuntime::notify_layout_and_scroll`); live `dispatch_click`, `dispatch_input`, `dispatch_submit`, and `dispatch_keydown` with `event.preventDefault()` (`last_event_default_prevented()`)
- `new Promise`, `then`, `catch`, `finally`, and `Promise.resolve`, `reject`, `all`, `allSettled`, `race`, `any`
- A promise resolved with another promise follows it. A class instance with a `then` method is called like one
- A rejection with no handler is counted (`unhandled_rejections()`), fires `PromiseRejectionEvent` (`unhandledrejection` / `window.onunhandledrejection`) on `CinderDomHost`, and does not stop the page
- `setTimeout`, `setInterval`, `clearTimeout`, `clearInterval`, `queueMicrotask`. `requestAnimationFrame` runs as a timer
- `async function`, async arrows (also called in place, as in `(async () => { ... })()`), async callbacks passed to `then`, timers, and `queueMicrotask`
- `await` suspends the async function. It resumes from a microtask, so code after the call runs first. This works inside `if`, `while`, `for`, `for...of`, blocks, and `try`/`catch`/`finally`
- `for await...of` over async generators (`async function*` / `[Symbol.asyncIterator]` on `cinder::vm::Vm`) and over an array of values and promises
- Overlapping calls of one async function keep their own parameters and locals
- An async call that is not awaited, from the script or from inside another async function, still runs to its end

Not supported, or different:

- On the legacy AST interpreter (when a script is not routed to `cinder::vm::Vm`), `for await...of` iterates arrays of values/promises rather than custom `[Symbol.asyncIterator]` objects
- Objects with a `then` property that are not class instances are plain values
- An `await` in a `switch`, a `do...while`, a loop condition, or at the top level of a script waits in place. It runs the event loop until the promise settles instead of yielding
- `async` class methods return a promise, but their awaits wait in place
- A callback created inside an async function gets a copy of that function's locals, not a live link
- On the legacy AST interpreter, `unhandled_rejections()` is counted without firing a window event (`CinderDomHost` dispatches `PromiseRejectionEvent` / `unhandledrejection`)

Limits: a turn spends at most 200,000 steps (`MAX_EXECUTION_STEPS`), script source is capped at 256 KiB, `fetch()` bodies are capped at 2.5 MiB (`MAX_SCRIPT_FETCH_BODY`), and WebAssembly calls are bounded at 5,000,000 instructions (`MAX_WASM_STEPS`), 640 call frames (`MAX_WASM_CALL_DEPTH`), and 2,560 linear-memory pages (160 MiB). Every microtask, timer callback, and resumed `await` costs steps, so a promise flood, a timer that sets itself again, or an endless `setInterval` is stopped with a reason (`abort_reason()`) instead of hanging. At most 128 timers and 8,192 queued microtasks are kept at once. ES2022–ES2024 DOM scripts automatically route through `eval_with_cinder_engine` (`cinder::vm::Vm` + `CinderDomHost`) or the C++20 `CinderVM` Live DOM Host Bridge; other scripts that use the event loop, DOM, or `WebAssembly` run on the Rust interpreter.

## CSS support

The crate docs list every property. These are the newer parts and their limits.

### Parsing and the cascade

- Order: user-agent defaults, then author rules sorted by cascade layer (`@layer` statement, block, nested, and anonymous layers in first-declaration order, followed by unlayered rules), `@scope` ancestor hop proximity (inner scopes beat outer scopes at equal specificity), selector specificity, and source order, then the `style` attribute, then `!important` author rules with inverted cascade layer precedence (earlier layers beat later layers and unlayered `!important`), then `!important` in the `style` attribute.
- CSS-wide keywords (`initial`, `inherit`, `unset`, `revert`, `revert-layer`) and the `all` shorthand are resolved per property across user-agent and cascade-layer snapshots. `@property --name { syntax; inherits; initial-value; }` registers custom property inheritance and initial values.
- Strings, backslash escapes, and the body of an unquoted `url(...)` are skipped when looking for `{`, `}`, and `;`, so a brace or semicolon inside them doesn't break the sheet.
- `@media` reads `min-width`, `max-width`, and `prefers-color-scheme` (only `dark` matches). The page is a `screen`, so `all` and `screen` match and `print` doesn't. `not`, `only`, `and`, and comma lists work, and nested `@media` is combined with the outer one.
- `Document::style_sheets` lists every `<link>` and `<style>` in document order with its `media` attribute. `parse_css_with_media` parses one sheet under that media, and `Stylesheet::append` puts sheets together in order.

### Selectors

- Supported: all four combinators; `::before` and `::after` pseudo-elements (`content: "..." | attr(...)`); CSS Nesting (`&` parent selector substitution and nested style/at-rules inside style blocks); attribute selectors with every operator and the `i` and `s` flags; `:is()`, `:where()`, `:not()`, and `:has()`; `:scope` (matching the active `@scope` root or document `:root`); `:host`, `:host()`, and `:host-context()` (on shadow host elements); `:nth-child()`, `:nth-last-child()`, `:nth-of-type()`, and `:nth-last-of-type()`, with `of S` on the child ones; the structural pseudo-classes (`:root`, `:empty`, `:first-child`, and the rest); `:link` and `:any-link`; the interactive and target states (`:hover`, `:active`, `:focus`, `:focus-visible`, `:focus-within`, `:target`, `:target-within` when set on `Document`); the form states (`:checked`, `:default`, `:disabled`, `:enabled`, `:required`, `:optional`, `:read-only`, `:read-write`, `:placeholder-shown`, `:valid`, `:invalid`, `:user-valid`, `:user-invalid`, `:in-range`, `:out-of-range`, `:indeterminate` on `progress`); `:open`, `:closed`, `:defined`, `:lang()`, and `:dir()`; and CSS escapes. Specificity follows the selector spec.
- Valid but never match: pseudo-elements other than `::before` and `::after`, vendor-prefixed (`-vendor-*`, `-moz-*`, `-ms-*`) pseudo-elements and pseudo-classes; namespace prefixes other than `*|`, since `@namespace` isn't read; and states such as `:visited`, `:autofill`, `:fullscreen`, `:modal`, `:popover-open`, the media playback states, and `:state()`. The full list is on `Selector`. `:indeterminate` on radio buttons doesn't match either, and `:dir(auto)` reads as left to right.
- A selector nested more than 64 deep (`MAX_SELECTOR_NESTING`) or longer than 640 compounds (`MAX_SELECTOR_COMPOUNDS`) drops its list.
- `Document::query_selector`, `Document::query_selector_all`, `Document::matches_selector` (`Element.matches`), and `Document::closest` (`Element.closest`) support descendant, child (`>`), next-sibling (`+`), and subsequent-sibling (`~`) combinators, attribute selectors (`=`, `~=`, `|=`, `^=`, `$=`, `*=` with `i`/`s` flags), `:is()`, `:where()`, `:not()`, `:has()`, `:nth-child(An+B)`, `:first-child`, `:last-child`, `:only-child`, `:empty`, `:root`, `:scope`, `:checked`, `:disabled`, `:enabled`, `:host`, `:host()`, `:host-context()`, and `:defined`.

### Gaps and sizes

- `row-gap`, `column-gap`, `gap`, and the old `grid-` names take lengths (including `ch`), percentages, `calc()`, and `normal`. Grid uses them between tracks. Flex rows use `column-gap` between items and `row-gap` between lines; flex columns use `row-gap`. A `row-gap` percentage counts as 0 when the container's height isn't set.
- A set `height` is the height. Content that doesn't fit overflows, and is clipped when `overflow` is `hidden`, `auto`, or `scroll`.
- Attributes on the `html`, `head`, and `body` tags are kept, so `<body style>`, `<body class>`, and `<html lang>` work.

### Flexbox and Grid

- Flexbox: `flex-direction` (`row`, `row-reverse`, `column`, `column-reverse`), `flex-wrap` (`nowrap`, `wrap`, `wrap-reverse`), `flex-flow`, `order`, `flex` / `flex-grow` / `flex-shrink` / `flex-basis` with an iterative `min`/`max` clamping freeze loop, `justify-content`, `align-items` (including first-baseline `baseline`), `align-self`, `align-content` multi-line cross-axis distribution (`stretch`, `flex-start`, `center`, `flex-end`, `space-between`, `space-around`, `space-evenly`), and 4-edge `auto` margins.
- Grid: `grid-template-columns` and `grid-template-rows` with `px`, `%`, `fr`, `auto`, `min-content`, `max-content`, `fit-content()`, `minmax()`, and `repeat()` (including `repeat(auto-fill, ...)` and `repeat(auto-fit, ...)` on column tracks); `grid-auto-rows` and `grid-auto-columns` multi-track cycling; `grid-template-areas` and named `grid-area`; `grid-auto-flow` (`row`, `column`, `row dense`, `column dense`); `grid-column`, `grid-row`, their `-start` / `-end` longhands, and numeric `grid-area`, with line numbers, negative lines, and `span N`; `order`; `justify-items`, `justify-self`, `align-items`, `align-self`, `justify-content`, `align-content`, `place-items`, `place-self`, `place-content`, and 4-edge `auto` margins inside grid areas.
- Not supported on Grid: named grid lines (`[line-name]`), `subgrid`, and implicit tracks before line 1 (such an item starts at line 1). Lines past 1000 are clamped. An `auto` column acts as `1fr`.

### `ch`

- Supported on `width`, `height`, `max-width`, the offsets, `margin`, `padding`, `border-width`, `border-radius`, `font-size`, `line-height`, `row-gap`, `column-gap`, `gap`, and `calc()`. One `ch` is the advance of `0` in the system font when `anvil-ttf` loads one (Linux and Windows); otherwise it is half the font size, the advance layout uses for every character.

### `position: sticky` and `overflow: auto | scroll`

- Supported: `top`, `right`, `bottom`, and `left` (`px`, `%`, and the other length units) against the viewport or the nearest ancestor with hidden overflow, bounded by the parent's content box. Viewport stickiness is applied at draw time for the scroll position, in every raster path and at every zoom; `hit_test_scrolled` finds boxes where they are drawn. `top` wins over `bottom` and `left` over `right`.
- Scrollable overflow containers (`overflow: auto` and `overflow: scroll`) clip their children, maintain per-element scroll offsets (`Document::node_scroll_offset`, `Document::set_node_scroll_offset`), hit-test under the cursor via `LayoutBox::find_scrollable_container`, and paint a 6px overlay scrollbar track and thumb when content overflows. Sticky boxes inside an overflow container are placed once; horizontal page scrolling is not supported.

### Transforms

- Supported: `transform` with up to 16 of `translate()`, `translateX()`, `translateY()`, `scale()`, `scaleX()`, `scaleY()`, `rotate()`, `skew()`, `skewX()`, `skewY()`, and `matrix()`; standalone `translate`, `scale`, and `rotate` properties; `transform-origin` with keywords, lengths, and percentages. Painting and `hit_test` use the transformed shape. Moves and even scales draw directly; other transforms are resampled with smoothed edges. A box's own clip turns with it; clips from its ancestors stay screen-aligned. A transform that cannot be inverted draws nothing and is never hit.
- Not supported: 3D functions, `perspective`, `transform-style`, `transform-box`, and `calc()` inside a function. Transforms do not change layout or scrollable size, and they do not become the containing block for fixed or absolute descendants (those are still drawn through the transform). Inline boxes are not transformed. A rotated or skewed layer is drawn into a buffer of at most 2048 pixels per side.

### Opacity, transitions, and animations

- Supported: `opacity` (one group per box); `transition` and its longhands; `animation` and its longhands with `@keyframes`, iteration counts including `infinite`, all four directions, and all four fill modes; `ease`, `linear`, `ease-in`, `ease-out`, `ease-in-out`, `cubic-bezier()`, `steps()`, `step-start`, and `step-end`. Lengths, colors, opacity, and transforms blend, along with margins, padding, `border-radius`, `font-size`, `row-gap`, and `column-gap`. They run through `compute_styles_animated` with an `Animator`, whose `tick(now_ms)` takes the time from any clock and says whether another frame is needed.
- Not supported: transition and animation events, `animation-play-state`, `animation-composition`, `transition-behavior`, shortened reverse transitions, and blending `auto` with a length. `compute_styles` and the other plain cascade functions do not animate. At most 16 transitions and 16 animations per element.

## Build

Clone this repository, `anvil-browser` (which houses the in-tree `engines/prism` and `engines/cinder` engines), and the libraries below as sibling directories.

```text
../anvil-browser
../anvil-engine
../anvil-image
../anvil-json
../anvil-ttf
../anvil-gpu
../anvil-compress
../anvil-video
../anvil-cipher
../anvil-hpack
../anvil-pqc
```

`anvil-image` links `anvil-compress`; `anvil-video` links `anvil-cipher`, `anvil-compress`, and `anvil-gpu`.

Rust 1.99.1 or newer, and Go 1.22 or newer (for the pure-Go `anvil-json` 0.4.0 / `v.04` and `anvil-compress` 0.4.0 / `v.04` companion repositories built by `build.rs`). A C++20 compiler is optional. If none is found, the C++ files are skipped and the Rust paths are used.

```text
cargo test
```
